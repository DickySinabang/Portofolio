Earth textures used by the hero 3D scene (src/components/sections/EarthScene.tsx).

earth-day.jpg      NASA Blue Marble (Visible Earth), 4096x2048, via thematicmapping.org / github.com/turban/webgl-earth
earth-day-2k.jpg   the same picture at 2048x1024, used only by the CSS fallback planet
earth-clouds.jpg   cloud density (grayscale) from the same source, 4096x2048
earth-water.jpg    ocean mask, same source, resized to 2048x1024
earth-lights.jpg   NASA "Earth at night" city lights, 2048x1024, via the three.js examples (github.com/mrdoob/three.js)

The underlying imagery is NASA Earth Observatory data, which NASA publishes for public use
(https://www.nasa.gov/nasa-brand-center/images-and-media/). Please keep a credit such as
"Imagery: NASA Visible Earth" if you publish the site, and check the terms of the sources above yourself.
